# 작은 섬 탐험

지도 위를 오가며 탐험하고, 주사위(1D20)로 판정하며 자동 전투를 하는 실시간 웹 게임입니다.
HTML 파일 하나로 돌아가며, 설치할 것이 없습니다.

## 실행하기

- `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.
- 배경음악(`bgm.mp3`)은 `index.html`과 같은 폴더에 있어야 나옵니다. 화면을 처음 누르면 시작되고, 오른쪽 아래 🔊 버튼으로 끄고 켭니다.
- GitHub Pages를 켜면 인터넷 주소로도 플레이할 수 있습니다. (저장소 **Settings → Pages → Branch: main / root**)

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 게임 전체 (화면, 규칙, 데이터, 대사) |
| `bgm.mp3` | 배경음악 (Eternal Mists Loop) |
| `game_data.xlsx` | 게임 데이터와 대사를 정리한 엑셀 (스크립트, 장소, 의뢰, 전투, 장비, 상점 등) |

## 주요 기능

- 안개가 걷히는 지도: 가 본 길과 지금 갈 수 있는 길만 보임
- 이동 중 랜덤 사건, 자동 전투(공격·방어 반응·기믹 대응), 도망
- 7가지 스탯과 캐릭터 만들기, 1D20 판정(20 크리티컬 / 1 펌블)
- 마을별 상점·대장간·훈련장·여관, 무기 분류와 3단계 장비
- 건물 안에서 받고 보고하는 의뢰 7개
- 타자 효과로 나오는 장소 묘사와 NPC 대화

## 고치는 방법

`index.html` 안의 `[번호] 제목` 주석이 각 부분의 위치입니다. 예를 들면:

- `[1] 색깔 모음` — 화면 색
- `[5] 장소 데이터` — 장소와 길
- `[20] 의뢰` — 의뢰 목록과 대사
- `[27] 마을 대사` — 상점·여관 대사
- `[32] 배경음악` — 음악 파일 이름과 음량
